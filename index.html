행동:AI 인프라 학습 시 서버/GPU 하드웨어 계층과 네트워크 병목 구조를 연계 분석함

상황:취업 목표를 위해 비실무자 상태에서 SKT ALEPH 부트캠프에 도전함

결과:오류에 타협하지 않고 GitHub Pages를 통한 첫 웹 배포 및 자체 검증을 100% 완수함
